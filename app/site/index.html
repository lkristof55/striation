Every createis a bullet.

the grooves are how it was built.

one groove per striation · depth = weight · angle = fnv1a(token) · twist 5.5°

The library walks the create transaction once and emits about seventeen families of striations: compute budget, relay tip, lookup table, instruction order, create and buy variant, mint suffix, signers. Each one is a token with a weight. This bullet is engraved from those tokens, one groove each, and nothing else.
